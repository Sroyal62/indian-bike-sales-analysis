# Project Description

This project focuses on analyzing Indian bike sales data to extract meaningful business insights. The dashboard provides a comprehensive view of sales performance, pricing trends, and customer distribution across different regions, brands, and time periods.

The analysis helps in understanding:

Sales trends over the years
Brand-wise performance
Regional demand distribution
Price variation and resale trends
Customer preferences based on fuel type

The dashboard is designed using data visualization techniques to support data-driven decision-making.

# Problem Statement

The Indian bike market is highly competitive with multiple brands and models. Businesses often struggle to:

Identify top-performing brands and models
Understand regional sales trends
Analyze price vs resale value
Track yearly manufacturing and sales growth
Segment customers based on preferences

# Key Insights / KPIs
Total Price Analysis
Total Bikes Sold
Resale Price Comparison
Average Price by Brand
Sales Distribution by State
Top 10 Models by Price
Fuel Type Distribution
Price Distribution across City Tiers
